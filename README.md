# UC-Patch-Maker
Overlay of Undercards' Patch Notes page, to allow custom user input that persists between saves, carries many similar features to UC Cardmakers

---------------------------
Editor Controls:
---------------------------
While editing a change:
* Enter  - Confirm Edit
* Escape - Cancel Edit
* (Ctrl + Up) and (Ctrl + Down) - Cycle through Class Colors
* (Shift + Up) and (Shift + Down) - Reorder Position in Balance Section
* Apply a variety of case-sensistive color-coded words such as cost, ATK, HP, G, rarities, SOULS, etc. 

Manual Inputs:
* Underline text - Encapsulate text inside underscores (i.e. _text_ ), easy for resembling Artifacts or new Keywords.
* Highlight text - Encapsulate text inside curly brackets (i.e. {text} ), easy for resembling existing Cards within effects.
* Switch effect text - Encapsulate text inside double square brackets (i.e. [[text1]] or [[text2]] ), easy for resembling Switch1 and Switch2 effects.

--------------------------
Features:
--------------------------

Overlay Patch Notes: Toggle button that places the custom patch notes directly above official patch notes, with a preserved layout

Viewer Mode Toggle: Users can compile their changes into a presentable format, ready for official-looking screenshots and the like
* Text will be formatted to match official terms on Undercards, such as keywords, tribes, stat changes, etc.

Automatic Save/Load: Custom Patch data is saved between sessions, and can be reset fully using the "Reset Data" button on double click
* Saving is triggered when unfocusing from text changes, Adding/Deleting a change, or collapse/uncollapsing a balance section

Color Cycling: Users can cycle between "Buff" "Nerf" "Rework" and "Other" classes per change using keyboard shortcuts

Collapse/Uncollapse Balance Sections: Ability to "hide" any sections deemed unnecessary. These will be invisible when presented in Viewer toggle

Add/Delete Entries: Users can increase or decrease the number of entries in a balance section, but each must always have at least 1

Reorder Entry Position: Users can change the orientation of each entry, in their respective balance section
